# ai自学通

中文优先的学习网站：**按目标与水平定制课程**、**把经过核实的公开教学视频接入课程**、**真实可提交的随堂测验**、**实战与实验室项目**、**本地保存的学习进度**；界面为原创设计（暖色编辑风 + 抽象轨道学习伙伴，不含任何上游角色形象）。

> 品牌说明：本产品现名 **ai自学通**（`ai` 为小写）。改名只影响用户可见文案——`localStorage` 键（`studymate.state.v1`）、备份文件里的 `app` 标识（`StudyMate-Web`）、Worker 名与 Durable Object 迁移名等技术标识**保持不变**，因此改名前后已有的进度与备份仍可继续导入使用。

同时提供可选的 **AI 建课** 能力：把 AI 代理 Worker 部署到你自己的 Cloudflare 账号，由 Worker 保管供应商密钥并限制调用次数，网站只填一个 Worker 地址。

- 上游灵感与功能参考：[Miaotofu01/Study-Mate](https://github.com/Miaotofu01/Study-Mate)（MIT License, Copyright (c) 2026 Cattofu）。本项目为独立重写，能力对照与平台限制见 [`docs/capability-mapping.md`](docs/capability-mapping.md)，商业化与上线条件见 [`docs/commercialization-plan.md`](docs/commercialization-plan.md)。
- 零运行时依赖：原生 ES 模块 + 原生 CSS，构建脚本只做复制与自检，**不需要 npm install** 即可运行测试与构建。
- **纯静态前端**：全部资源使用相对路径 + hash 路由，可直接部署到 `https://<user>.github.io/<任意仓库名>/`。

## 快速开始

```bash
# 运行测试（单元 + 集成，TAP 输出）
npm test

# 构建静态站点到 dist/
npm run build

# 真实浏览器端到端测试（需要本机有 Edge 或 Chrome）
npm run test:browser

# 本地预览（默认 http://127.0.0.1:4173）
npm run serve
```

> Windows 下建议使用 `npm.cmd`；本机 TLS 需要系统证书时的联网脚本用 `node --use-system-ca ...`。

## 教学视频：来源与核实

- 收录标准：平台**官方认证账号**（3Blue1Brown、尚硅谷、黑马程序员）或**官方开放课程页**（MIT OpenCourseWare）。
- 每条视频都记录：标题、作者、来源平台、时长、知识点、入选理由、核实日期。
- 核实方式可复现：

  ```bash
  node --use-system-ca tools/verify-videos.mjs    # 或 npm run verify:videos（脚本已带 --use-system-ca）
  ```

  脚本会调用哔哩哔哩公开接口核对存在性 / 合集标题 / 分 P 标题 / UP 主 / 时长与账号认证状态，并核对 MIT OCW 页面可访问性，结果写入 [`docs/video-verification.json`](docs/video-verification.json)。逐条说明见 [`docs/video-sources.md`](docs/video-sources.md)。

- **诚实边界**：我们验证的是「来源页面与元数据可达且一致」，**没有验证嵌入播放器一定播放成功**（受地区、登录、浏览器策略影响）。因此界面上标注为「播放未验证」，并始终保留「打开来源页」兜底链接；本站不下载、不转存任何视频。
- 本项目的构建环境无法访问 YouTube，因此**没有收录 YouTube 视频**，也没有对其可达性做任何声称。

## AI 通道（可选）

两种模式，均为可选；未配置时课程、视频、测验与进度功能完全可用。

1. **代理模式（推荐）**：部署 [`worker/`](worker/README.md) 到自己的 Cloudflare 账号，

   ```bash
   npm install -D wrangler
   npx wrangler login
   npx wrangler secret put PROVIDER_API_KEY --config worker/wrangler.toml
   npx wrangler secret put IP_SALT --config worker/wrangler.toml
   npx wrangler deploy --config worker/wrangler.toml
   ```

   然后在网站「设置 → AI 通道」填入 Worker 地址。供应商密钥保存在 Worker 机密中，**浏览器不会拿到**；
  前端等待上线的截止时间是 `src/core/ai-client.js` 的 `WORKER_DEADLINES`（**四个端点统一 120 秒**：`outline` / `lesson` / `generate` / `explain`），刻意**高于** Worker 的 `PROVIDER_TIMEOUT_MS` 默认值（90 秒）并留出网络与校验余量——否则前端会在一次已经计费的有效生成返回前中断。如果你把 `PROVIDER_TIMEOUT_MS` 调大，请同步把 `WORKER_DEADLINES` 调到「新超时 + 至少 30 秒」。另：**模型尝试一旦发出即计入当日额度且可能产生费用**，失败或输出无效也不例外；配额由 Durable Object 原子控制（默认 **200 次/访客/天、800 次/全站/天**，为本项目选定的默认值，可在 Worker 变量中调整）。

2. **直连模式（次级，仅用于讲解）**：浏览器直接调用你自己填写的 OpenAI 兼容接口。密钥只写入 `sessionStorage`（关闭标签页即失效），导出备份时被剔除；界面上明确提示「密钥会暴露给该接口方，且无法限制调用次数」。

AI 生成内容的处理原则：

- 服务端严格校验结构（禁止 HTML/脚本/链接、限制长度与数量、要求唯一 id、要求前置无环、要求每课有正文与练习、至少有动手单元、测验必须有解析）；
- `videoIds` 只能来自**服务端打包的同一份已核实视频目录**（`worker/src/catalog.js` ← `src/data/videos.js`）；前端提交的「视频库」只作为主题提示，伪造条目一律忽略并计入 `meta.ignoredClientVideoEntries`，编造 id 会被拒绝；找不到合适视频就如实标注「无匹配」；
- 前端再做一次二次校验（防御被替换的恶意服务端），生成内容一律标注 **「AI 生成 · 请自行核对」**，预览确认后才写入本地；
- **课程模板只提交受信任的 `templateId`**（前端与服务端共用 [`src/data/course-templates.js`](src/data/course-templates.js) 这一份清单）：服务端按 id 取出受控的教学取向说明，未知/伪造 id 一律退化为「自定义」，客户端文本永远不会进入提示词；不传模板的请求与加入模板前完全一致；
- 术语名允许 **1 个字**（「键」「值」这类单字术语合法）；空串与超长（>40 字）仍然被拒绝。

### 分阶段建课、续跑与用量（重要）

- **两步生成**：先取大纲（`POST /api/course/outline`），再对每个知识点各取一次正文（`POST /api/course/lesson`），最后在前端拼装并通过二次校验后才给出预览。单次调用生成整门课会稳定触发输出截断，因此不再使用单次生成；`POST /api/course/generate` 与 `POST /api/explain` 仍然保留可用。
- **失败续跑只补未完成的知识点**：「大纲 + 已完成知识点」这类中间进度**只保留在当前标签页的内存里**（没有写入 localStorage）：刷新或关闭标签页即丢失。点「续跑未完成的知识点」只会重发没有完成的部分；已确认完成的知识点永远不会再次请求（每次请求都是一次可能被计费的模型尝试）。重试前会先等在途调用结算，不会出现两批请求交叉。
- **换了输入就重新开始**：生成身份包含全部需求字段（主题 / 目标 / 水平 / 每周时长 / 单次时长）、课程模板与**规范化后的 Worker 地址**。任何一项变化都会按新需求从头生成，不会拿旧正文凑当前需求（界面上会如实提示）。
- **不做重复计费式的重复点击**：同一批输入只允许一次进行中的生成；重复点击会恢复到同一次运行；同一批输入再次点击会直接复用已有结果，不重新发请求。
- **用量如实汇总**：预览与失败面板展示的是**大纲 + 全部知识点**的服务端回报用量（输入 / 输出 / 合计 tokens，以及模型尝试次数）。这是服务端回报值，**不等于供应商账单的精确金额**；失败同样可能已经被供应商计费。
- **有界**：单次生成有总时间预算（15 分钟），超出即停止继续请求；不做自动无限重试——要不要重试由你决定。

## 隐私、备份与部署

- **所有学习数据只存在浏览器的 localStorage**（键名 `studymate.state.v1`）：课程进度、笔记、收藏、任务勾选、测验记录、定制计划、AI 生成课程。
- **核心功能不依赖任何后端**：没有账号、没有遥测，课程/视频清单/测验/进度/课件全部在浏览器本地完成。可选 AI 是唯一会访问后端的部分，用的是**你自己部署的 Worker**（前端只保存 Worker 地址，不保存供应商密钥）。
- 外部请求只发生在明确动作上：你**主动点击**加载某个视频播放器、打开「设置中的自动加载视频」开关（默认关闭）、或点击「生成 / 讲解 / 登录 / 检查登录状态」时才会请求第三方或你配置的 Worker。唯一的例外是**你已在本机登录**（存有登录令牌）时，页面加载会向**你自己的** Worker 校验一次会话，以便正确显示登录状态；没有令牌时一个请求都不发，也从不向任何第三方发起后台请求。
- 备份：在「我的进度」导出 JSON（**不含任何密钥**）；导入时会做严格清洗（拒绝危险协议、丢弃伪造的「已认证 / 已验证」标记、忽略 `__proto__` 之类的危险键名）。
- GitHub Pages 部署：把本目录作为仓库根目录推送后，工作流 [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) 会自动构建并发布 `dist/`；也可以在仓库 Settings → Pages 中选择「GitHub Actions」。任意仓库子路径都能运行（无根绝对路径引用，`404.html` 兜底回到首页）。
- **商业化与上线条件**：GitHub Pages 的可用条款对「纯静态个人项目」与「以商业目的运营的站点」并不等同；在做店铺/收款之前请先看 [`docs/commercialization-plan.md`](docs/commercialization-plan.md)（其中包含薄利多销的定价思路、成本参数与许可证边界）。生产环境若确需商业用途，可能需要改用允许商业使用的托管（例如 Cloudflare Pages），本仓库**目前没有**做任何商业部署或收款配置。
- 本项目**没有**执行任何远程推送或公开发布。自动化测试**全部使用本地模拟的供应商响应**，不产生任何费用。
- 真实调用边界（如实记录）：最近一次有界真实验证已跑通**完整链路** —— 1 次大纲 + 8 个知识点，共 9 次调用、约 49 秒、无失败无重试，拼装与前端二次校验通过（8 个单元、8 套测验、3 个动手单元、匹配 15 条已核实视频）。服务端回报用量：输入 12,392 / 输出 21,939 tokens。此前只验证到「大纲 + 前 4 个知识点」。
- 注意：上面的 usage 只来自**成功响应**，失败与超时通常不返回用量，因此它是真实支出的**下界**，不是账单金额，更不是人民币费用。可复现方式：`node tools/verify-staged-live.mjs`（预演，不发请求）与加 `--live` 的真实运行（**会产生真实费用**：一次最多 1 门课、1 次大纲 + ≤12 个知识点、不自动重试、失败即停并保留已完成结果）。

## 已知限制（不夸大）

- 嵌入播放器的成功播放未验证，请使用「打开来源页」兜底。
- 进度只在本机浏览器，不支持多设备同步；换设备请导出/导入备份。
- AI 功能需要你自己提供 Worker/接口与额度；生成内容未经人工逐条审核，请自行核对。
- 公开站点上的静态前端无法隐藏共享密钥：私有部署请叠加 Cloudflare Access 等访问控制。
- 未收录 YouTube 视频（构建环境无法访问，未做任何可达性声称）。
