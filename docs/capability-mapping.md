# 能力对照：上游 Study-Mate → StudyMate Web

上游 [Miaotofu01/Study-Mate](https://github.com/Miaotofu01/Study-Mate)（MIT, Copyright (c) 2026 Cattofu）是一个 AI 学习工作流 / HTML 课件引擎，而不是普通 Web 应用。下表逐项说明本项目保留了什么、怎么落地、以及哪些做不到。

图例：✅ 完整保留并网页化　🟡 保留但形态改变　⛔ 纯静态站点无法保留

| --- | --- | --- | --- |
| 课程总览 | ✅ | 课程详情页：简介、学习成果、单元数、预计时长、进度条 | 内容为原创撰写，不复制上游课件 |
| 依赖 + 状态着色的概念路线图 | ✅ | 纯 SVG/CSS 分层路线图：锁定 / 可学习 / 学习中 / 已掌握四态着色，同时标出「需先完成」 | 依赖关系来自课程数据；顺序由拓扑排序计算 |

## 平台边界（为什么这样取舍）

1. **没有后端就没有密钥**：静态站点无法隐藏共享密钥，所以 AI 走「自建 Worker 代理 + 配额」或「用户自带密钥」两条路，绝不内置密钥。
2. **没有服务端就没有云同步**：进度以 localStorage 为准，配套导出/导入与严格导入清洗，保证换设备可用、坏数据不可执行。
3. **没有浏览器信任边界之外的沙箱**：所有模型/导入数据都在渲染前被清洗（禁止 HTML / 脚本协议 / 任意 URL），并使用 `textContent` 而非 HTML 拼接。
4. **不虚构能力**：视频播放、AI 可用性、跨设备同步等未验证或未实现的能力，都在界面和文档中如实标注。
